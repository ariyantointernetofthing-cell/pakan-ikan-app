Setup Firebase untuk Pakan Ikan Otomatis

Ikuti langkah 1 sampai 6 sambil membuka Firebase Console di tab lain. Di langkah 7, tempel hasilnya dan halaman ini membuatkan isi config.js, kode ESP32, dan Rules secara otomatis.

0 dari 6 langkah selesai

1Buat proyek Firebase

Wadah untuk database dan akun login.

  1. Buka console.firebase.google.com, login dengan akun Google.
  2. Klik Create a project (atau Get started with a Firebase project).
  3. Nama proyek: pakan-ikan. Centang persetujuan jika ada, klik Continue.
  4. Jika ditawari Gemini atau AI assistance, boleh dimatikan. Klik Continue.
  5. Matikan Google Analytics, lalu klik Create project. Tunggu sampai selesai, klik Continue.

2Buat Realtime Database

Tempat ESP32 dan aplikasi bertukar data.

  1. Menu kiri: klik Realtime Database di bawah tulisan Project shortcuts. Jika tidak ada, buka Databases & Storage lalu Realtime Database.
  2. Klik Create Database.
  3. Database location: pilih Singapore (asia-southeast1). Klik Next.
  4. Pilih Start in locked mode, klik Enable.
  5. Di atas tabel data muncul alamat seperti https://pakan-ikan-xxxxx-default-rtdb.asia-southeast1.firebasedatabase.app/. Klik ikon salin di sebelahnya dan simpan, nanti ditempel di langkah 7.
Jika diminta upgrade ke paket Blaze (berbayar), batalkan. Realtime Database bisa dipakai gratis di paket Spark. Pastikan kamu memilih Realtime Database, bukan Firestore Database.

3Aktifkan login Email/Password

  1. Menu kiri: buka Security lalu Authentication. Klik Get started.
  2. Di tab Sign-in method, klik Email/Password.
  3. Aktifkan saklar pertama (Enable). Saklar kedua (Email link) biarkan mati. Klik Save.

4Buat 2 akun

Satu untuk alat ESP32, satu untuk kamu login di aplikasi HP.

  1. Masih di Authentication, buka tab Users, klik Add user.
  2. Akun alat: email esp32@pakanikan.id, password buat sendiri (minimal 6 karakter). Klik Add user. Email ini tidak perlu email sungguhan.
  3. Klik Add user lagi. Akun admin (kamu): email kamu sendiri (misalnya Gmail) dan password untuk login di aplikasi. Pengguna lain nanti ditambahkan langsung dari aplikasi, tidak perlu lewat sini.
Catat kedua password. Password akun alat akan masuk ke kode ESP32, password akunmu dipakai saat login di HP.

5Daftarkan aplikasi Web dan salin konfigurasinya

  1. Klik Project Overview di menu kiri, lalu klik tombol + Add app di bawah nama proyek.
  2. Pilih ikon </> (Web).
  3. App nickname: Pakan Ikan App. Jangan centang Firebase Hosting. Klik Register app.
  4. Muncul kode berisi const firebaseConfig = { ... };. Blok dan salin seluruh kode yang tampil, lalu klik Continue to console.
Lupa menyalin? Buka lagi Project settings, gulir ke Your apps, pilih Pakan Ikan App, lalu pilih Config di bagian SDK setup and configuration.

6Biarkan pendaftaran akun tetap aktif

Dibutuhkan supaya admin bisa menambah pengguna dari aplikasi.

  1. Authentication, tab Settings, pilih User actions.
  2. Pastikan Enable create (sign-up) tercentang. Jika tadi sempat dimatikan, centang lagi lalu Save.
Tetap aman: orang yang membuat akun sendiri tidak bisa melihat atau mengubah data, karena Rules (langkah 7C) hanya mengizinkan admin, ESP32, dan pengguna yang ditambahkan admin.

7Buat file otomatis

Semua isian hanya diproses di halaman ini dan tidak disimpan atau dikirim ke mana pun.

A. Isi file config.js
Buka 2_aplikasi_android\app\src\main\assets\config.js dengan Notepad, hapus semua isinya, tempel ini, simpan. Lalu jalankan UPLOAD_KE_GITHUB.bat.


    
B. Bagian atas kode ESP32

    
Tempel ke file kredensial.h (salinan dari kredensial.contoh.h) di folder firmware/arduino/PakanIkanFirebase/, ganti baris #define yang sama.

    


    
C. Rules Realtime Database

    
Firebase Console, buka Realtime Database, tab Rules. Hapus semua isinya, tempel ini, klik Publish.

    


    
Cek akhir: setelah ESP32 di-upload dan menyala, buka Realtime Database tab Data. Jika muncul pakanIkan lalu status dengan angka yang berubah tiap 5 detik, Firebase sudah bekerja.
