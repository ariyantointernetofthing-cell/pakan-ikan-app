Alat harus sedang online. Alat mencoba WiFi baru selama 20 detik. Jika gagal, alat otomatis kembali ke WiFi lama. ESP32 hanya bisa WiFi 2,4 GHz.

Alat offline atau pindah tempat? Atur lewat hotspot
  1. Cabut daya ESP32. Tahan tombol beri pakan, colokkan daya, terus tahan 3 detik sampai LED berkedip cepat. (Jika alat tidak menemukan WiFi saat menyala, mode ini juga aktif sendiri.)
  2. Di HP, buka pengaturan WiFi dan sambungkan ke PakanIkan-Setup dengan password 12345678. Jika muncul "tidak ada internet", pilih tetap tersambung.
  3. Halaman setup biasanya terbuka sendiri. Jika tidak, matikan data seluler lalu tekan tombol di bawah.
  4. Pilih WiFi, isi password, tekan Simpan dan sambungkan. Sambungkan HP kembali ke internet.
