Update Firmware via Bluetooth

Versi firmware alat
-
  1. Di laptop, Arduino IDE: Sketch > Export Compiled Binary. Kirim file .bin (bukan yang berakhiran merged atau bootloader) ke HP.
  2. Tekan Aktifkan mode update. Alat mematikan WiFi dan LED menyala tetap. (Bisa juga: tahan tombol alat 8 detik saat menyalakan.)
  3. Dekatkan HP ke alat, nyalakan Bluetooth (dan Lokasi untuk Android 11 ke bawah), lalu tekan Pilih file dan mulai.

WiFi Alat (ESP32)

Tersambung ke
-
-

Alat mencoba WiFi baru selama 20 detik. Jika gagal, alat kembali ke WiFi lama. ESP32 hanya bisa WiFi 2,4 GHz.

Alat offline atau pindah tempat? Atur lewat hotspot
  1. Cabut daya ESP32. Tahan tombol beri pakan, colokkan daya, tahan 3 detik sampai LED berkedip cepat, lalu lepas.
  2. Di HP, sambungkan WiFi ke PakanIkan-Setup (password 12345678). Jika muncul "tidak ada internet", pilih tetap tersambung.
  3. Halaman setup biasanya terbuka sendiri. Jika tidak, matikan data seluler lalu tekan tombol di bawah.
